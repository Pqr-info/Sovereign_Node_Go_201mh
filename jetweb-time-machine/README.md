# JetWeb Time Machine (Antigravity Integration)

JetWeb Time Machine is a deterministic temporal protection module running as a flagship extension for the Antigravity module ecosystem. 

It provides hyper-fast, natively integrated chronological rollbacks for WSL environments and IDE configuration states using a combination of VCS-style deep chain differencing disks and active credential honey tokens.

## Mechanics
The engine operates strictly under the Post-Pay Recovery Funnel model:
1. **Free Tier:** Unlimited Baseline creation, continuous filesystem monitoring, automatic differencing checkpoint generation, and IDE fingerprinting.
2. **Paid Tier:** Irreversible temporal rollback execution, Vault intervention, and filesystem mount recovery.

## Installation
Drop the `jetweb-time-machine` folder into your Antigravity module path. The Antigravity core will automatically parse `module.json` and present the Time Machine via its internal control plane.

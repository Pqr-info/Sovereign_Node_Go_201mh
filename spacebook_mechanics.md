| ❌ **Pure Rewind** | Directly reverting time to before prediction is *impossible*. The NPU does not store raw sensory data—only high-level state graphs. | Prevents exploits; maintains causality integrity. |
| 🔁 **Branch Echoing** | Failed branches can be re-run in a new context (e.g., same jump, but now with enemy distracted). Each echo consumes CATs and reduces confidence by 15% per echo. | Max 3 echoes per sequence. |

> 💡 *Design Insight*: This creates *narrative weight*—players learn which mistakes are recoverable (and how), turning failure into a *predictive learning loop*, not frustration.

## **3. The Valkey Global Brain: Memory Synchronization**

### **3.1 Architecture Overview**
- **Valkey Clusters** act as the *semantic memory backbone*.
- Each cluster shard is replicated across ≥7 peers using CRDT-based eventual consistency.
- Memories are stored as `SemanticEvent` records with:
  - Vectorized content (`embedding: []`)
  - Causal timestamp (Lamport + vector clock hybrid)
  - Trust score (`trust_score = f(valence, source_reliability, consensus_confidence)`)

### **3.2 Memory Sync Protocol**
1. **Local Event Generation**  
   Agent detects event → generates `SemanticEvent` with:
   ```ts
   {
     type: "TRADE_SUCCESS" | "ALLY_FORMED" | "COMBAT_VICTORY",
     context: ["sector_epsilon", "ally_id:agent_8b3d"],
     embedding: model.encode(event_description),
     valence: 0.67, // computed via affective model
     tags: ["diplomacy", "high_tech"]
   }
   ```

2. **Consensus Inference Layer**  
   - Sent to local Valkey shard + broadcast to *relevant* peers (via semantic routing).
   - Peers compare embedding similarity with *their own memory graph*.
   - If `cos_sim > 0.85`, event is tentatively accepted; else → triggers *consensus voting*.

3. **Consensus Voting (Lightweight)**  
   - Uses *Federated Byzantine Quorum Systems* (FBQS): Each peer selects a set of trusted peers (e.g., based on historical sync fidelity).
   - If ≥70% of quorum confirms event embedding similarity → memory is merged into *global consensus state*.

4. **Memory Compression & Eviction**  
   - Low-valence, low-frequency events decay via exponential forgetting:  
     `retention_prob = e^(-Δt / τ)`, where `τ` scales with agent importance.
   - Redundant memories are compressed using *semantic hashing* (e.g., BERTopic-style clustering).

> ✅ **Result**: Agents globally share *meaning*, not raw data. Two agents can “remember” the same alliance *differently* yet coherently—enabling nuanced diplomacy.

## **4. NPC Interaction Mechanics**

### **4.1 Trading: Value-Driven Negotiation Engine**

**Mechanism**: *Multi-objective Pareto Optimization with Trust Constraints*

- Each trade offer is scored as:
  ```
  score = α·(utility_gap) + β·(fairness_deviation) - γ·(trust_risk)
  ```
  where:
  - `utility_gap` = difference between agent’s valuation and offer
  - `fairness_deviation` = deviation from *recently accepted fair trades* (learned via local regression)
  - `trust_risk` = inverse of `(1 + avg_trust_in_counterparty * market_stability)`

- **Negotiation Protocol**:
  1. Agent A broadcasts offer with semantic tag: `"offer://commodity_X/price_Y?risk_tolerance=0.7"`.
  2. B receives, computes `score`, and responds with counteroffer if `score < threshold`.
  3. If both score ≥0 (within tolerance), trade executes; else → *mediation protocol*:
     - Randomly selected peer acts as neutral arbiter.
     - Arbiter evaluates via *semantic memory similarity* to past trades.

> 🧠 **Example**: A trader with high `curiosity_driven` may accept a low-utility item if its `embedding_similarity` to their goal vector (e.g., `"tech_evolution"` > 0.9).

## Sovereign Temporal Auto-Healing (STC Backpressure & Recovery)

- NPU mesh load
- temporal drift Φ(t)

- NPC cognitive volatility

Define three tiers based on Φ(t) and STC verdict:

*   **Tier 1 — Elevated Drift (Warning):** Φ in [0.1, 0.3], STC = Deny
*   **Tier 2 — High Drift (Critical):** Φ in [0.3, 0.7], STC = DenyAndFreeze
*   **Tier 3 — Extreme Drift (Infundibulum):** Φ ≥ 0.7, STC = DenyAndFreeze + hard clamps

**3.1 NPU Mesh & 5D Navigation**

**Notes**
- `ws.tokenSignature` is set to the second part of the token string.  
- `forceDisconnectBySignature` iterates `wss.clients` and closes matching sockets with close code **4001** and reason **token_revoked** by default.  
- The function returns a deterministic summary object listing closed connections and any failures.

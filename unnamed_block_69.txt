**Alternative**: send token in `Sec-WebSocket-Protocol` header as `token.<token>` if your client library supports subprotocols.

### Security and Operational Notes

- **Protect the token issuer** with your operator authentication and authorization. The issuer must only return tokens to authorized operators.  
- **Short TTL**: tokens are short‑lived (default 5 minutes). Rotate `TOKEN_SECRET` regularly.  
- **No sensitive data in token**: token payload contains only operator id and expiry. Do not embed secrets.  
- **Transport security**: run WebSocket over TLS (wss://) in production. The HMAC token is an additional layer, not a replacement for TLS.  
- **Token revocation**: for immediate revocation, maintain a small in‑memory blacklist keyed by token signature or operator id and check it in `verifyToken`.  
- **Audit**: attach `ws.operator` to connections and record connection events in Jetweb lineage if desired.  
- **Rate limiting**: enforce connection rate limits on the issuer endpoint and on WebSocket connections to prevent abuse.  
- **Canonical logging**: record token issuance and connection events with canonical JSON for audit.
